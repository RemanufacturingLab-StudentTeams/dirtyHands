# Python

To start interacting with the neo4j database, it is required to install python and some modules. Python is the language that handles the conversion from excel files to graph structure.

## Installing Python

Installing Python for windows can be done using the following link:

[Download Python](https://www.python.org/downloads/)

Go through the setup and once done, restart the computer.

## Installing required modules

To support the Python scripts and database handling, several modules need to be installed. 

Open Command Prompt and run:

```bash
python -m pip install neo4j==6.2.0 pandas==2.3.0 openpyxl==3.1.5 hypernetx==2.3.13 matplotlib==3.10.3
```

At this point everything should be installed and good to go.
